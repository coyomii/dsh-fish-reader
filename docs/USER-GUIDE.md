# DSH Fish Reader 使用指南

DSH Fish Reader 是一个本地 TXT / EPUB 阅读器。它把小说正文放进 DeepSeek Harness 输入框的待输入文字区，不新增行，也不会改变输入框高度。

阅读内容只保存在本机，不会发送到当前对话，也不会调用模型。

![DSH Fish Reader 阅读示例](images/reader-example.png)

正文显示在输入框占位区，工具栏按钮位于“完全权限”旁边，右侧是进度和搜索。

## 能做什么

- 导入本地 TXT / EPUB 小说；
- 自动识别 UTF-8、UTF-16、UTF-32、GB18030、Big5 等文本编码；
- 每本书单独保存阅读位置，下次从“继续”回到原处；
- 单行阅读，自动按输入框宽度排版；
- 上一段 / 下一段、显示 / 隐藏、自动隐藏；
- 普通搜索、正则搜索、查找上一个 / 下一个；
- 输入百分比跳转，例如 `12%`、`12.5%`、`100%`；
- 快捷键可以自己改；
- 删除书库条目不会删除原始 TXT / EPUB 文件。

## 快速开始

1. 点击左侧栏底部的书本图标，打开 **DSH Fish Reader 书库**；
2. 点击 **导入 TXT / EPUB**，选择一本或多本小说；
3. 在书库中点击 **打开** 或 **继续**；
4. 当输入框为空、没有聚焦、正文未隐藏时，小说会显示在输入框的待输入文字区；
5. 点击输入框任意位置就会进入输入状态，正文立即隐藏，可以直接打字。

## 输入状态和阅读状态

- **阅读状态**：正文显示在输入框占位区；
- **输入状态**：点击输入框后进入，正文隐藏，恢复原生 placeholder；
- 进入输入状态后，再点击输入框外的空白，**不会自动回到小说**；
- 要恢复阅读，使用：
  - 工具栏眼睛按钮；
  - `Alt+/`；
  - 从书库打开 / 继续；
  - 在“阅读已隐藏、但不是输入状态”时点上一段 / 下一段。

输入状态下，上一段 / 下一段不会生效，也不会偷偷翻页。

## 工具栏

输入框工具栏里、**完全权限**旁边有三个按钮：

- **上一段**：回到上一段；
- **下一段**：前进到下一段；
- **眼睛**：显示 / 隐藏阅读。

没有打开书时，这三个按钮显示为禁用；它们的外观在三种状态下保持一致。

正文行右侧会显示：

- 阅读进度，例如 `12.5%`；
- 搜索图标。

## 搜索和跳转

按 `Alt+F`，或点击正文行右侧的搜索图标。

### 普通搜索

- 输入文字后，点左右箭头查找上一个 / 下一个；
- `Enter` 查找下一个，`Shift+Enter` 查找上一个；
- 命中后搜索框保持打开，右侧显示当前序号 / 总数，例如 `3/17`；
- 不循环：到开头或结尾时提示没有更多匹配。

### 正则搜索

- 点击搜索框里的 **正则** 按钮；
- 直接输入 JavaScript 正则表达式，不带 `/.../`，使用 `u` 标志，区分大小写；
- 例如 `\d+`、`第[一二三四五六七八九十]+章`；
- 正则模式下，`12.5%` 会按正则处理，不再触发百分比跳转。

### 百分比跳转

普通搜索模式下输入：

- `0%`：开头；
- `12%` / `12.5%`：跳到对应位置；
- `100%`：最后一段。

## 快捷键

默认快捷键：

| 快捷键 | 操作 |
| --- | --- |
| `Alt+,` | 上一段 |
| `Alt+.` | 下一段 |
| `Alt+/` | 显示 / 隐藏阅读 |
| `Alt+F` | 搜索 / 百分比跳转 |

可以在书库的 **设置 → 快捷键** 里修改。自定义组合必须包含 Alt、Ctrl 或 Meta。

## 设置

书库 **设置** 页可以调整：

- 每段最多字数（默认 50，窗口变窄时会自动减少）；
- 自动隐藏秒数（默认 30，0 表示不自动隐藏）；
- 下一段是否去除首尾空白；
- 上一段 / 下一段 / 显示隐藏 / 搜索的快捷键。

## 数据与隐私

- 书籍正文保存在本机 IndexedDB；
- 设置、书库目录和阅读进度保存在 localStorage；
- 不发送聊天消息，不调用模型，不上传书籍内容；
- 删除书库条目只删除导入的副本和进度，不会改动原始文件；
- 浏览器 profile 不同，书库不会自动同步。

如果你之前安装过旧版 Shadow Reader，首次启动会自动迁移旧书库和进度。

## 常见问题

### 点击输入框后小说不见了

这是正常的输入状态。正文让位给原生输入框，可以直接打字。

### 点了输入框外空白，小说没有回来

进入输入状态后，失焦不会自动恢复阅读。点工具栏眼睛、按 `Alt+/`，或从书库继续。

### 生成回复时三个按钮消失了

控制按钮位于输入框工具栏。Agent 运行中宿主会切换工具栏为 activity 状态，按钮会暂时跟着隐藏；生成结束后恢复。

### 导入失败

- 全部文件失败时会显示错误汇总；
- TXT 会拒绝明显的二进制或严重误码内容；
- EPUB 目前只提取正文，不支持 DRM、图片、CSS 排版和 EPUB 目录跳转；
- 超大文件受浏览器内存限制。

### 搜索很慢

正则搜索会在全书范围内查找匹配。非常复杂的正则表达式可能让搜索变慢，建议使用更具体的模式。

## 兼容性

已在 DeepSeek Harness `0.2.2-rc.5` Desktop（Windows）上验证。

如果宿主升级后输入框布局变化，正文覆盖位置可能需要适配。
